# From $100 to $500 in 30 days

A tiny program that writes a short, executable 30-day plan to `/output/entry.txt`.

Built for the make.fun bounty: https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138

## How to run it

```sh
python3 main.py
```

It needs no dependencies and no network. It creates `/output` if needed and writes exactly one file, `/output/entry.txt`, with no trailing newline added.

## The plan, in plain words

On day one, spend $40 on API credits and $12 on a domain name. Then sell a $25 same-day Shopify speed and SEO fix report to owners of slow Shopify stores, found with BuiltWith. Email 100 store owners a day, deliver the report as a PDF within 2 hours of payment through Stripe, and put every dollar earned back into reaching more stores. Twenty sales in 30 days makes $500.
